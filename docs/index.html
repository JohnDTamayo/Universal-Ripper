What's included

  • Search YouTube Music and rip any track
  • Batch-download full Spotify and Apple Music playlists
  • Output as MP3, M4A, FLAC, or WAV
  • Pick any folder as your save location
  • Up to 8 tracks downloading at once

Everything is bundled — no Python, ffmpeg, or other setup required.

First launch

These builds aren't code-signed, so your operating system will show a warning the first time you open the app. This is normal for independent software without a paid signing certificate.

macOS — open the .dmg and drag the app to Applications. Then right-click the app and choose Open (don't double-click it the first time) and confirm. If macOS still blocks it, go to System Settings → Privacy & Security and click Open Anyway.
Windows — unzip the folder anywhere and run RippedRipper.exe. At the SmartScreen prompt, click More info → Run anyway.

Where do my files go?

By default, rips are saved to a Ripped Ripper folder inside your Music folder. You can change this any time with the Save to picker in the app.
